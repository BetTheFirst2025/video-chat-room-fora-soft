## Load (task 52)

**Инструмент:** Artillery 2.x
**Сценарий:** 4 участника в комнату, `room:join` + `chat:message` + `room:leave`.
**Окружение:** Windows 11, Node.js 20 LTS, 1 инстанс сервера, localhost.

**Профиль нагрузки:**

- Warm-up: 5 комнат/сек × 20 сек
- Ramp-up: 20 комнат/сек × 30 сек
- Peak: 30 комнат/сек × 20 сек

**Результаты:**

| Метрика                        | Значение   |
| ------------------------------------- | ------------------ |
| Комнат обработано     | **1300**     |
| Участников (сокетов) | ~5200              |
| WebSocket emit'ов                   | 7800               |
| Ошибок (vusers.failed)          | **0**        |
| Response time p50                     | 0.3 мс           |
| **Response time p95**           | **0.7 мс** |
| Response time p99                     | 1.0 мс           |
| Max                                   | 13 мс            |
| Общее время                 | 1 мин 16 сек |

**Выводы:**

- 1 инстанс Node.js держит **1300+ комнат (5200+ сокетов)** **без ошибок**.
- p95 = **0.7 мс** — **в 700 раз меньше** целевых 500 мс (TDD §9.1).
- Медиа не идёт через сервер (mesh P2P) — нагрузка только на signaling + chat.
- **Узкое место:** память под `RoomRegistry` + `messages` (cap 500 сообщений на комнату).
- **Репорт:** `server/load-report.html` (`cd server && npm run load:report`).
